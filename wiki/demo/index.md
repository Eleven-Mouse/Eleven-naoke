# demo 知识集合

这里是示例知识集合。把你的 Markdown 知识页面放进 `wiki/<集合名>/`，执行 `kb index` 后即可语义检索。

页面约定（借鉴而非复制）：

- 文件名用 `类型-主题.md`，如 `module-`、`concept-`、`troubleshoot-` 前缀帮助归类（可选约定，索引器不依赖前缀）。
- frontmatter 写 `title`、`tags`、`date`、`source`，方便人和机器共同理解。
- 一个页面围绕一个知识对象，写"可复用的结论"，不写一次性操作流水。
